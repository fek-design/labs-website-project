# OpenSpec Visual Mockups & Design Reference Library

This folder is the dedicated repository for UI/UX visual mockups, Figma exports, screenshots, and design artifacts that OpenSpec uses to guide exact UI/UX recreation.

## Supported File Formats
- Images: `.png`, `.jpg`, `.jpeg`, `.webp`, `.svg`
- Documents: `.pdf`

## How it is Used
1. Place visual mockups or design screenshots in this folder (`openspec/mockups/`).
2. OpenSpec workflows (`/opsx-propose`, `/opsx-apply`, delta specs, and design documents) reference the mockups stored here to ensure deliberate, pixel-accurate visual replication.
